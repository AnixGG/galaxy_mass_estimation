# Student Camp Projects 

## Overview
Данный репозиторий посвящён разработке и применению методов глубокого обучения для анализа карт реликтового излучения (CMB), полученных в экспериментах Planck и ACT.

Он включает в себя два основных компонента:
1. **Сверхвысокое разрешение карт Planck с использованием диффузионных моделей** — повышение углового разрешения до уровня ACT.
2. **Измерения массы скоплений галактик с помощью ACT+Planck** — модели глубокого обучения для оценки массы скоплений на основе SZ.

## Requirements
- Python 3.9+  
- PyTorch  
- Astropy, Healpy, NumPy, SciPy, Matplotlib  

## Resources
